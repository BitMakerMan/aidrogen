What runs here

Qwen3.8-Flash-Next is a mixture-of-experts model: 125 billion parameters in total, but only about 6 billion are used for each token. Most of the weight sits in 24,576 small "experts", and every token calls just a few of them.

That is what makes cheap hardware useful. The experts do not need a fast GPU; they need a lot of memory close to a GPU. A Tesla M10 is four small GPUs on one card, 8 GB each, built for virtual desktops and now sold off by data centres. Two of them give 64 GB of video memory, enough to hold the whole model next to the RTX 3060.

What was built

The engine is Strata, with the Maxwell support of Strata-maxwell. That fork drove up to four M10 GPUs and only 2-bit expert formats.

This project extends it to eight M10 GPUs and adds the kernels the M10 was missing for the IQ3_S model: three new input formats and a new output stage, rewritten so the old cards read memory efficiently. Each new kernel was checked against the RTX 3060's own results before it was allowed to run.

Results

IQ3_S, the best-quality quantization, is about 10% slower than the 2-bit IQ2_XS. On a coding agent that trade is worth it: fewer wrong answers mean fewer rounds of corrections.

The new output stage reads its weights as 16-byte blocks instead of 2-byte pieces. On the M10 it went from 271 to 118 microseconds per layer, and its results are identical to the old kernel bit for bit.

Two models, one switch

IQ3_S: the default

Highest-quality quantization of the model. 54.3 tok/s on coding prompts, 128k context, loads in about 4 minutes from the SSD. Used for real work.

IQ2_XS: the fast one

2-bit quantization, about 10% faster: 60.3 tok/s on the same prompts. Kept on the hard disk and ready with one command; loads in about 11 minutes from there.

Both models cannot sit in video memory at once (about 31 and 47 GB of experts against 76 GB in total), so switching means reloading.

How it got here

Built by one person, on a used workstation, over two weeks of evenings and nights.

  1. 25 October

    A storm of PCIe errors

    The first M10 produced about 10,500 correctable errors per second. The cause was electromagnetic: the NVMe drive sat next to the card's unshielded riser. Moving the drive to slot 3 and forcing the M10 slots to Gen1 brought it to zero.

  2. 27 October

    A full backup, and a driver experiment

    The whole system was imaged to a hard disk before any risky change. A driver unlock was then tested: +2.5% on prompt reading, nothing on writing. It was removed.

  3. 5 November

    The second M10, and eight GPUs instead of four

    The engine accepted at most four M10 GPUs. Seven places in the code were changed to accept eight. IQ2_XS reached 68.7 tok/s in a real coding session.

  4. 6 November, night

    IQ3_S refuses to start

    The M10 kernels only understood 2-bit formats, and a safety check stopped the engine. The check is right: a format read with the wrong kernel gives plausible but wrong answers.

  5. 7 November

    New kernels, checked against the 3060

    Three input formats and a native output stage were written for the M10, each compared with the RTX 3060 to one part in 100,000 before use. IQ3_S loaded on all eight GPUs for the first time.

  6. 8 November

    The planar output stage, and production

    Profiling showed where the time went. The output stage was rewritten for the M10's memory and became 2.3 times faster. IQ3_S passed the 128k test and a 10-minute soak, and went into service.

Rebuild it

The outline is here. The exact commands, configuration and checks are in the full guide.

  1. Hardware

    A workstation with three usable PCIe slots, PCIe 8-pin power for each M10, risers, and airflow: the M10 is passively cooled. Keep NVMe drives away from unshielded risers.

  2. BIOS

    Set the M10 slots to Gen1 explicitly; "Auto" is not enough. On the Z440, add pci=realloc to the kernel command line so both M10 switches get their memory windows.

  3. Host and driver

    Proxmox VE 9 with the kernel pinned, and NVIDIA driver 580.196.07, the last branch that supports Maxwell. Keep the installer file: you will need it again.

  4. Container and CUDA

    A privileged Debian 12 LXC with the NVIDIA devices passed through, and CUDA 12.9. CUDA 13 no longer supports the M10.

  5. Engine

    Build the iq3 branch with a recent CMake (the 3.25 of Debian 12 cannot handle CUDA 12.9's C++20 dialect).

  6. Model

    Download and prepare Qwen3.8-Flash-Next IQ3_S with Strata's setup.py: about 84 GB of model files plus a 49 GB prepared pack.

  7. Configure and start

    Eight Maxwell devices, the CUDA order with the 3060 first, an expert cache of 988, 128k context. At start the log must show eight round-trip gates passed.

  8. Measure

    Use the bench tool with a fixed protocol and compare only runs made the same way, in the same session.
